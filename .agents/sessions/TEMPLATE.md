# 会话记录

## 会话信息
- 日志标识: 文件名中的安全短标识，不要求等于实际会话 ID
- 实际会话 ID: 实际值，或无法取得
- 开始时间: 真实本地日期时间及已知时区或偏移
- Agent 与工具: 实际已知信息，未知部分注明未知
- 关联计划与会话: 相关相对路径或来源说明，没有则写无

## 第 1 轮

### 学员请求
脱敏后的项目相关原话，省略处明确标记。

### 状态
处理中、已完成、未完成或受阻，按事实填写。

### 理解与决定
学员实际表达的目标、关键决定和确认；没有新增决定时注明。

### 操作与工具结果
实际操作、必要的命令摘要、相关文件相对路径和关键结果。

### 验证
实际执行的检查及结果；未执行的检查及原因。

### 对外答复
本轮对学员可见的进展说明、提问和最终答复，保持先后顺序。

### 待办与交接
真实未完成项、阻塞及下一步；没有则写无。
