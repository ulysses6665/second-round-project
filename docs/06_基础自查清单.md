# 06 基础自查清单

做到哪就查到哪，暂未学习的标记为待学。

## 学习与数据

- [ ] 能解释自己的类、表和几次关键 commit。
- [ ] 当前代码、SQL 可运行，数据重启后仍在。
- [ ] 运行方式、AI 参与和未完成内容已写清。

## 业务

- [ ] 草稿不占钱，提交才冻结；经费不足仍保留草稿。
- [ ] 用途必填，申请金额大于零且最多两位小数。
- [ ] 提交后不能直接改原始信息。
- [ ] 批准不超申请，减额差额立即恢复。
- [ ] 拒绝、取消只释放剩余冻结，不能重复释放。
- [ ] 结算允许零元，不超过批准金额；结束后不能重复办理。
- [ ] 每步都满足“总预算 = 可用 + 冻结 + 已使用”，各项非负。
- [ ] 数据库操作失败，没有只改一半的数据。

## 权限与页面

- [ ] 成员只能处理本人申请，老师不能自批，各角色不越项目操作。
- [ ] 后端校验身份、权限和状态，不能只靠页面隐藏按钮。
- [ ] 原申请、批准、结算金额分开展示，未发生与零元能区分。
- [ ] 失败保留输入并说明原因，刷新后结果仍正确。

发现问题时记下：**怎样复现 → 预期与实际结果 → 原因 → 修复后怎样检查。**

例如：“600 元申请批准为 500 元后取消，多恢复了 100 元。”把它复现、修复并提交，就是一次完整的学习成果。
