# CampusERP：边学边做的全栈项目

你将完成一个校园经费管理小系统：成员申请采购，老师审批，财务登记实际花费。

从一个 Java 类、一张表开始，随着学习逐步加入业务、接口和页面。**学到哪里，就做到哪里；完成一小步，检查后提交 commit。**

## 阅读顺序

| 文档 | 什么时候看 |
|---|---|
| [01 项目介绍与准备](01_项目介绍与准备.md) | 开始前，了解项目并确定第一个小目标 |
| [02 基础业务需求](02_基础业务需求.md) | 实现功能时，查业务规则 |
| [03 学习路线](03_学习路线.md) | 学了新知识，找可以动手的部分 |
| [04 学习记录与 AI 使用](04_学习记录与AI使用.md) | 提交代码、记录进度时 |
| [05 进阶需求](05_进阶需求.md) | 基础完成后，再继续挑战 |
| [06 基础自查清单](06_基础自查清单.md) | 完成一部分后，检查是否正确 |

第一次先读 01 和 02。今天的目标可以只是“写一个成员类，创建两个成员并打印”。

基础版本只有一级审批。进阶内容不要求一开始完成。
