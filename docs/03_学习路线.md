# 03 学习路线

每学一个知识点，就找一个能做的小目标。顺序可以跟随课程调整。

| 学到什么 | 可以先做什么 | 怎样检查 |
|---|---|---|
| Git、需求分析 | 建仓库，写需求理解与学习计划 | 能说清经费怎样变化 |
| Java 类与对象 | 写成员类，创建两个成员 | 运行 main，检查输出 |
| 方法、集合、枚举 | 查询内存中的成员，表达申请状态 | 修改数据，观察结果 |
| SQL、表关系 | 建成员表，再关联项目与申请 | 执行 SQL，核对查询 |
| 数据库访问 | 保存、读取一张草稿 | 重启后仍能读到数据 |
| Service、事务 | 逐步实现提交、审批、取消、结算 | 核对状态与经费，尝试失败情况 |
| Spring Boot、Controller | 把已有业务提供为接口 | 发请求，同时查数据库 |
| Vue、JavaScript / TypeScript | 先静态列表，再表单与接口联调 | 浏览器操作，刷新后核对 |
| 调试、测试 | 修复一次错误并保留验证 | 重跑旧流程，确认没有改坏 |

## 三个小提醒

**先简单，再完善。**刚学 Java 时写普通类就够了，不必加框架注解。SQL 也可以独立提交，不用等前后端联通。

**复用已有成果。**学到 Service 后，把控制台业务整理进去；学到 Controller 后调用 Service；学到 Vue 后连接接口。

**每一步都能检查。**可以先打印、手算，后来再用 SQL、接口和自动测试。保存可执行代码与 SQL，不只保存截图。

## 六周参考节奏

- 第 1～2 周：需求、Git、Java 基础、SQL。
- 第 3～4 周：数据库访问、Spring Boot、业务方法与接口。
- 第 5～6 周：Vue、联调、修复和运行说明。

进度按课程与个人基础调整。尚未学到的部分写清楚即可。

代码目录可以随着需要再建立：早期 Java 示例、SQL、后端、前端。保留有用的练习，业务迁移后说明旧示例用途，避免维护两套冲突的实现。
